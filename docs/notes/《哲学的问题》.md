# 哲学在做什么？
有人说哲学是爱智慧，有人说哲学是人生的慰藉，又有人说哲学就是追寻真理。所以哲学是什么？从小爱看哲学书的我，根本不懂什么是哲学，听别人玩弄看似深奥玄妙的词藻便觉得遥不可及；而当自己也开始熟练地在QQ空间发一些看似深奥的句子时，便沾沾自喜起来；又或者打开网易云音乐的评论区，最高赞的评论似乎是有极其哲学深度的，能让人看完之后郁郁了。哲学，难道就是故弄玄虚吗？或者是一门只属于高智商者的学问？

罗素的《哲学的问题》回答的就是，**哲学究竟在回答什么问题**。“世界上有没有一种如此之确切的知识，以至于一切有理性的人都不会对它加以怀疑呢？”这样一个看似简单的问题，却很难回答。哲学是去帮助我们搞清楚这类问题令人困惑的地方，并且找到我们日常思想中的混乱与模糊，加以限定，然后再批判地解答。

哲学帮助我们建立和谐的信仰体系，避免形成荒谬的自相矛盾的观点。在进行哲学思考之前，我们常常会对一些基础性问题抱有怀疑态度，笛卡尔的我思故我在是一个经典的例子。首先对自我的存在产生怀疑，然后假设有一个魔鬼故意制造幻觉让我以为我真实地生活着。然而如果我不存在，那魔鬼也不可能欺骗我，因此我存在。哲学思考帮助我们确定了自我的存在这样一个基础信仰，继续从基础性问题的信仰加以推演，会形成系统的世界观与价值观。

因为每个人同一个问题的信仰是不同的，而这种信仰无关对错。当你试图回答一个问题的时候，你觉得无懈可击了，但其他人不见得认可你的答案。从这种意义上来讲，我认为辩论没有任何意义。

其哲学为回答这类根本性问题做出的贡献是，至少在最低限度上，我们能够相信一些常识，例如你“自己”存在的事实。

回到对书本的评价，《哲学的问题》讨论了现象与实在，物质的存在等问题。不同于其他哲学家晦涩难懂的语言，罗素的写作水平非常高，表达观点之清晰，文风之有趣，令人叹服。全书不长，建议作为哲学入门读物。
