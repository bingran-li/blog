# Measure Theoretic Probability
The first is to accept a random variable is a function with output in $\mathbb{R}$, hence can be integral in some way if we can define a measure properly on it's domain $\Omega$, which can be any abstract space.
The core is to understand what is the meaning of **measurable random variable**, and why we are interested in (square) **integrable random variable**. For $f: (E,\mathcal{E})\rightarrow (F, \mathcal{F})$, we define that function is measurable if and only if it's pre-image $f^{-1}(A)$ is in $\mathcal{E}$ for all $A$ in $\mathcal{F}$. For direct explanation, we deal with random variable, which is a function maps from a space $\Omega$ (e.g. $\mathbb{R}$), to $\mathbb{R}$. The key feature is that, its output space is real field $\mathbb{R}$, hence we can talk about **integrability** of it.
$X: (\Omega,\mathcal{F})\rightarrow (\mathbb{R}, \mathcal{B})$.

## Conditional Expectation
Conditional Expectation $\mathbb{E}[X|\mathscr{F}]$ (exists when $X\geq 0$ or $X\in L^p$...) is essentially a random variable. If $X$ contains finer information than the conditioned sigma-algebra $\mathscr{F}$, $\mathbb{E}[X|\mathscr{F}]$ will be a constant on the "basic atomics" generating $\mathscr{F}$ that deliver less information. That is, when you observe some events contained in $\mathscr{F}$, you can only know the average value of $X$ of the events. On the other hand, we understand that if $X$ is measurable by $\mathscr{F}$, $\mathbb{E}[X|\mathscr{F}]=X$ because the information they contain are the same.

## Filtration
Filtration generated by a stochastic process (the most natural one) contains information of itself. Or, filtration is a sigma-algebra which is a collection of set, hence can represent all possible trajectories of this stochastic process 
Progressive measurable: fix $\omega$, $X_t(\omega)$ is a measurable function in $t$, which is also a path.

## Martingale
${X}_t$ is a martingale as a sequence of random variable, which can be studied by convergence of sequence, like $\{a_n\}$ in elementary calculus.
For example, if $X_t$ is sub-martingale (increasing) and bounded in $L^1$, then it converges almost surely.

## LLN and CLT
$X_1+\dots+X_n$ normalized by $n$ converges to $\mathbb{E}[X]$.
by $\sqrt{n}\sigma$ converges to $N(0,1)$ (CLT).
